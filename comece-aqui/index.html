O que é Programação Web?

Entendendo o básico antes de escrever código

Programação web é criar sites e aplicativos que funcionam no navegador. São três tecnologias principais que trabalham juntas:

HTML

Estrutura
O esqueleto

CSS

Estilo
A aparência

JavaScript

Interação
O comportamento

Como a web funciona (resumo)

1. Você digita um URL no navegador (ex: google.com)
2. O navegador faz uma requisição para um servidor
3. O servidor responde com os arquivos (HTML, CSS, JS)
4. O navegador monta a página e exibe na tela

Ferramentas Essenciais

O kit básico para começar a programar

1. Navegador (você já tem)

Use o Google Chrome ou Firefox. Ambos têm ferramentas para desenvolvedor (DevTools) essenciais para testar e depurar seu código.

2. VS Code — o editor de código

O Visual Studio Code é o editor mais usado por desenvolvedores web. É gratuito e existe para Windows, Mac e Linux.

Instalação

1. Acesse code.visualstudio.com
2. Clique em "Download" (seu sistema é detectado automaticamente)
3. Instale como qualquer programa
4. Abra o VS Code

Extensões essenciais

🔹 Live Server (Ritwick Dey)
   → Recarrega a página automaticamente quando você salva

🔹 Prettier (Prettier)
   → Formata seu código automaticamente

🔹 ESLint (Microsoft)
   → Ajuda a escrever JavaScript sem erros

🔹 Color Highlight (Sergii N)
   → Mostra a cor ao lado do código hexadecimal
🧪 Como instalar extensões no VS Code

Clique no ícone de blocos na barra lateral esquerda (ou Ctrl+Shift+X),
digite o nome da extensão e clique em "Install".

3. Terminal (prompt de comando)

O terminal é uma ferramenta de texto para dar comandos ao computador. No VS Code, abra com Ctrl + ' (acento grave).

Seu Primeiro Arquivo HTML

Mão no código — crie sua primeira página

Passo 1: Crie uma pasta para o projeto

1. No seu computador, crie uma pasta chamada "meu-site"
2. Abra o VS Code
3. Clique em File > Open Folder e selecione a pasta
4. No VS Code, clique em "New File" e nomeie como "index.html"

Passo 2: Digite este código

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Minha Primeira Página</title>
</head>
<body>
  <h1>Olá, mundo!</h1>
  <p>Estou aprendendo HTML.</p>
</body>
</html>

Passo 3: Veja no navegador

1. Clique com o botão direito no arquivo "index.html"
2. Escolha "Open with Live Server" (se instalou a extensão)
3 OU: abra o arquivo diretamente no navegador (dois cliques)
4. Pronto! Sua primeira página está no ar! 🎉
🧠 Dica: Sempre que você salvar o arquivo (Ctrl+S), o Live Server atualiza a página automaticamente. Você vê as mudanças em tempo real.

Estrutura de Pastas de um Projeto Web

Organização desde o início

Conforme seu projeto cresce, organizar os arquivos evita confusão. Use esta estrutura como padrão: 

meu-site/
├── index.html          # Página principal
├── css/
│   └── style.css       # Estilos
├── js/
│   └── script.js       # JavaScript
└── img/                # Imagens
    ├── logo.png
    └── foto.jpg

Este mesmo guia que você está usando segue essa estrutura.
