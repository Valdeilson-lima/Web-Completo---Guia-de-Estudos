01. Estrutura Básica do HTML

Todo documento HTML segue este esqueleto

<!DOCTYPE html>             <!-- Diz ao navegador que é HTML5 -->
<html lang="pt-BR">        <!-- Elemento raiz, lang define o idioma -->
<head>                      <!-- Metadados (não aparecem na página) -->
  <meta charset="UTF-8">   <!-- Codificação de caracteres (acentos) -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Título da página</title>  <!-- Aparece na aba do navegador -->
</head>
<body>                      <!-- Tudo que aparece na página -->
  <h1>Olá, mundo!</h1>
  <p>Meu primeiro parágrafo.</p>
</body>
</html>
🧪 Resultado visual:

Olá, mundo!

Meu primeiro parágrafo.

O que cada parte significa

<!DOCTYPE html>
  → Instrução para o navegador renderizar no modo padrão (HTML5)

<html lang="pt-BR">
  → Elemento raiz. O atributo lang ajuda leitores de tela e SEO

<head>
  → Metadados: charset, viewport, title, links de CSS, meta tags

<body>
  → Conteúdo visível: textos, imagens, vídeos, formulários, etc.
🧠 Dica: Sempre inclua meta charset="UTF-8" e meta name="viewport". Eles são essenciais para acentos e responsividade.

02. Tags de Texto

Títulos, parágrafos, formatação e citações

Títulos (headings)

<h1>Título principal</h1>     <!-- Apenas UM por página -->
<h2>Seção</h2>
<h3>Subseção</h3>
<h4>Detalhe</h4>
<h5>Detalhe menor</h5>
<h6>Detalhe mínimo</h6>

Parágrafos e formatação

<p>Parágrafo de texto.</p>
<p>Outro parágrafo.</p>

<strong>Texto importante (negrito)</strong>
<em>Texto com ênfase (itálico)</em>
<u>Texto sublinhado</u>
<s>Texto riscado</s>
<mark>Texto destacado (marca-texto)</mark>
<small>Texto pequeno (notas, legendas)</small>

<br>        <!-- Quebra de linha (não use para espaçamento!) -->
<hr>        <!-- Linha horizontal (separação temática) -->

Citações

<blockquote>
  Citação longa em bloco.
</blockquote>

<q>Citação curta inline</q>

<cite>Título de obra citada</cite>
🧪 Resultado visual:

Título h1

Título h2

Título h3

Negrito, itálico, sublinhado, riscado, destacado e pequeno.

"Citação em bloco com blockquote."

Citação curta inline — disse o autor.

🧠 Dica: Use <h1> apenas uma vez por página. Ele é o título principal e importante para SEO. Siga a hierarquia sem pular níveis (h1 → h2 → h3, nunca h1 → h3).

03. Listas

Ordenadas, não ordenadas e de definição

Lista não ordenada (ul)

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

Lista ordenada (ol)

<ol>
  <li>Primeiro passo</li>
  <li>Segundo passo</li>
  <li>Terceiro passo</li>
</ol>

<!-- Atributos úteis -->
<ol type="A">     <!-- A, B, C... (também: a, I, i, 1) -->
<ol start="5">     <!-- começa do 5 -->
<ol reversed>       <!-- ordem decrescente -->

Lista de definição (dl)

<dl>
  <dt>HTML</dt>
  <dd>Linguagem de marcação para criar páginas web.</dd>
  <dt>CSS</dt>
  <dd>Linguagem de estilo para dar aparência às páginas.</dd>
</dl>
🧪 Resultado visual:
  • Item não ordenado 1
  • Item não ordenado 2
  1. Item ordenado 1
  2. Item ordenado 2
HTML
Linguagem de marcação para criar páginas web.
CSS
Linguagem de estilo para dar aparência às páginas.
🧠 Dica: Use <ul> para listas sem ordem específica e <ol> quando a ordem importa (passos, rankings).

04. Links

Navegação entre páginas, seções e recursos

<!-- Link básico -->
<a href="https://google.com">Visite o Google</a>

<!-- Abrir em nova aba -->
<a href="https://google.com" target="_blank" rel="noopener noreferrer">
  Google (nova aba)
</a>

<!-- Link para uma seção da própria página (âncora) -->
<a href="#secao">Ir para seção</a>
<!-- ... -->
<h2 id="secao">Seção destino</h2>

<!-- Link para email e telefone -->
<a href="mailto:contato@exemplo.com">Enviar email</a>
<a href="tel:+551199999999">Ligar</a>

<!-- Link para download -->
<a href="arquivo.pdf" download>Baixar PDF</a>

<!-- Link com título (tooltip ao passar o mouse) -->
<a href="..." title="Descrição do link">Link com tooltip</a>
🧪 Resultado visual:

Link básico

Abre em nova aba

contato@exemplo.com

Passe o mouse aqui

⚠️ Importante: Ao usar target="_blank", sempre adicione rel="noopener noreferrer" por segurança (evita que a página alvo acesse a sua via window.opener).

05. Imagens & Mídia

Imagens, vídeos, áudio e iframes

Imagens

<!-- Básico — SEMPRE use alt para acessibilidade -->
<img src="foto.jpg" alt="Descrição da imagem">

<!-- Com tamanho explícito (evita layout shift) -->
<img src="foto.jpg" alt="..." width="800" height="600">

<!-- Responsivo com srcset -->
<img
  src="foto-600.jpg"
  srcset="foto-600.jpg 600w, foto-1200.jpg 1200w, foto-2000.jpg 2000w"
  sizes="(max-width: 600px) 100vw, 50vw"
  alt="Descrição"
>

<!-- Figura com legenda -->
<figure>
  <img src="foto.jpg" alt="...">
  <figcaption>Legenda da imagem</figcaption>
</figure>

Vídeo e Áudio

<!-- Vídeo -->
<video controls width="400">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  Seu navegador não suporta vídeo.
</video>

<!-- Áudio -->
<audio controls>
  <source src="musica.mp3" type="audio/mpeg">
  Seu navegador não suporta áudio.
</audio>

Iframe (incorporar conteúdo externo)

<iframe src="https://www.google.com/maps/embed?..."></iframe>
🧪 Exemplo de imagem:
♿ Acessibilidade: O atributo alt é obrigatório em imagens. Para imagens decorativas, use alt="" (vazio) — leitores de tela vão ignorá-la.

06. Tabelas

Dados tabulares organizados em linhas e colunas

<table>
  <caption>Título da tabela</caption>
  <thead>
    <tr>
      <th>Nome</th>
      <th>Idade</th>
      <th>Cidade</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>João</td>
      <td>25</td>
      <td>São Paulo</td>
    </tr>
    <tr>
      <td>Maria</td>
      <td>30</td>
      <td>Rio de Janeiro</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="3">Total: 2 pessoas</td>
    </tr>
  </tfoot>
</table>

Mesclagem de células

<td colspan="2">...</td>  <!-- ocupa 2 colunas -->
<td rowspan="3">...</td>  <!-- ocupa 3 linhas -->
🧪 Resultado visual:
Tabela de exemplo

🧠 Dica: Use <thead>, <tbody> e <tfoot> para organizar a tabela semanticamente. O <caption> funciona como título da tabela.

07. Formulários

Coletar dados do usuário com inputs, selects e botões

Estrutura básica

<form action="/enviar" method="post">

  <label for="nome">Nome:</label>
  <input type="text" id="nome" name="nome" required>

  <label for="email">Email:</label>
  <input type="email" id="email" name="email" placeholder="seu@email.com">

  <label for="senha">Senha:</label>
  <input type="password" id="senha" name="senha" minlength="6">

  <label for="idade">Idade:</label>
  <input type="number" id="idade" name="idade" min="0" max="150">

  <label for="cor">Cor favorita:</label>
  <input type="color" id="cor" name="cor">

  <label for="data">Data:</label>
  <input type="date" id="data" name="data">

  <fieldset>
    <legend>Sexo:</legend>
    <input type="radio" id="masc" name="sexo" value="M">
    <label for="masc">Masculino</label>
    <input type="radio" id="fem" name="sexo" value="F">
    <label for="fem">Feminino</label>
  </fieldset>

  <label for="interesses">Interesses:</label>
  <input type="checkbox" id="css" name="interesse" value="css">
  <label for="css">CSS</label>
  <input type="checkbox" id="html" name="interesse" value="html">
  <label for="html">HTML</label>

  <label for="pais">País:</label>

    <option value="">Selecione...</option>

  <label for="msg">Mensagem:</label>

</form>

08. Semântica HTML5

Tags que dão significado ao conteúdo

Tags semânticas principais

<header>   <!-- Cabeçalho da página ou seção -->
<nav>       <!-- Navegação principal -->
<main>      <!-- Conteúdo principal (único por página) -->
<article>   <!-- Conteúdo independente (post, notícia) -->
<section>   <!-- Seção genérica com tema próprio -->
<aside>     <!-- Conteúdo relacionado (sidebar, complemento) -->
<footer>    <!-- Rodapé da página ou seção -->
<figure>    <!-- Mídia com legenda (img + figcaption) -->
<time>      <!-- Data ou hora -->
<address>   <!-- Informações de contato -->

Por que usar semântica?

1. Acessibilidade — leitores de tela entendem a estrutura
2. SEO — Google dá mais relevância a conteúdo bem estruturado
3. Manutenção — código mais legível e organizado
4. Performance — navegadores otimizam a renderização
🧪 Layout semântico visual:
<header>
<nav>
<main>
<footer>

Estrutura típica: header → nav → main → footer

⚠️ Importante: Cada página deve ter apenas um <main>. Use <div> apenas quando nenhuma tag semântica for adequada.

09. Atributos

Globais, específicos e data-attributes

Atributos globais (funcionam em qualquer tag)

<div id="unico">           <!-- Identificador único -->
<div class="grupo">        <!-- Classe (pode repetir) -->
<div style="color:red">    <!-- Estilo inline (evite) -->
<div title="Tooltip">     <!-- Texto que aparece ao passar o mouse -->
<div lang="en">           <!-- Idioma do elemento -->
<div hidden>               <!-- Oculta o elemento -->
<div tabindex="0">        <!-- Ordem de foco no teclado -->
<div role="button">       <!-- Papel semântico (ARIA) -->
<div aria-label="Texto">  <!-- Rótulo acessível -->

<!-- data-* — atributos personalizados (acessíveis via JS) -->
<button data-user-id="123" data-status="ativo">Salvar</button>
/* JS: element.dataset.userId → "123" */

Atributos específicos por tag

<a href="..." target="_blank">
<img src="..." alt="..." width="200" height="150">
<input type="text" name="..." placeholder="..." required disabled>
<form action="/enviar" method="POST">
<video controls autoplay loop>
🧪 data-attributes no HTML: 
<button data-user-id="123" data-status="ativo">Salvar</button>

No JavaScript: button.dataset.userId → "123"

🧠 Dica: Use data-* para armazenar dados personalizados no HTML sem poluir classes ou IDs. É a forma padrão e semântica de associar dados a elementos.

10. Entidades & Símbolos

Como exibir caracteres especiais no HTML

Entidades HTML começam com & e terminam com ;. 

&lt;   → <    (less than — menor que)
&gt;   → >    (greater than — maior que)
&amp;  → &    (ampersand — e comercial)
&quot; → "    (double quote — aspas duplas)
&apos; → '    (apostrophe — apóstrofo)

&nbsp; → espaço (non-breaking space — não quebra linha)
&copy; → ©    (copyright)
&reg;  → ®    (registered)
&trade;→ ™    (trademark)

&deg;  → °    (grau)
&plusmn;→ ±   (mais ou menos)
&times;→ ×    (multiplicação)
&divide;→ ÷   (divisão)

&mdash;→ —    (travessão)
&ndash;→ –    (meia-traçãp)

&larr; → ←    (seta esquerda)
&rarr; → →    (seta direita)
&darr; → ↓    (seta baixo)
&uarr; → ↑    (seta cima)

&hearts;→ ♥   (coração)
&spades;→ ♠   (espadas)
&clubs; → ♣   (paus)
&diams; → ♦   (ouros)
🧪 Símbolos comuns:
© ® ™ ° ± × ÷ — ← → ♥ ♠
⚠️ Importante: Se você está escrevendo um post sobre HTML e quer mostrar tags como texto, use &lt;h1&gt; para exibir <h1> em vez de interpretar como HTML.

11. SEO & Meta Tags

Ajudando o Google a entender sua página

Meta tags essenciais

<head>
  <!-- Básicas -->
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Título da Página | Site</title>
  <meta name="description" content="Descrição com até 160 caracteres.">

  <!-- Open Graph (Facebook, LinkedIn, WhatsApp) -->
  <meta property="og:title" content="Título">
  <meta property="og:description" content="Descrição">
  <meta property="og:image" content="https://site.com/imagem.jpg">
  <meta property="og:url" content="https://site.com">
  <meta property="og:type" content="website">

  <!-- Twitter Card -->
  <meta name="twitter:card" content="summary_large_image">
  <meta name="twitter:title" content="Título">
  <meta name="twitter:description" content="Descrição">
  <meta name="twitter:image" content="https://site.com/imagem.jpg">

  <!-- Ícone da aba (favicon) -->
  <link rel="icon" href="favicon.ico" type="image/x-icon">

  <!-- Canonical (evita conteúdo duplicado) -->
  <link rel="canonical" href="https://site.com/pagina">
</head>

Boas práticas de SEO

1. Apenas UM <h1> por página (título principal)
2. Use <h2> a <h6> na hierarquia correta
3. Atributo alt descritivo em todas as imagens
4. URLs amigáveis (/produto/nome-do-produto)
5. Meta description relevante (130-160 caracteres)
6. Links internos entre páginas do seu site
7. Mobile-friendly (viewport + design responsivo)
8. Performance: carregamento rápido, imagens otimizadas
9. Open Graph para redes sociais
10. Sitemap.xml + robots.txt
🧪 Exemplo de preview em rede social:
og:image

exemplo.com

Título (og:title)

Descrição curta que aparece no preview do link...

🧠 Dica: As tags Open Graph og:* controlam como sua página aparece quando compartilhada no Facebook, WhatsApp, LinkedIn e outros. Sem elas, o preview fica genérico.

12. Boas Práticas & Checklist

Código limpo, acessível e performático

Checklist de qualidade HTML

☐ DOCTYPE html na primeira linha
☐ meta charset="UTF-8"
☐ meta name="viewport"
☐ lang definido no <html>
☐ Apenas um <h1>
☐ Hierarquia de headings correta (h1 → h2 → h3)
☐ alt descritivo em todas as imagens
☐ Labels associados a inputs (for = id)
☐ Uso de tags semânticas (<header>, <main>, <nav> etc.)
☐ Links com target="_blank" têm rel="noopener noreferrer"
☐ Código indentado e legível
☐ Validação W3C sem erros (validator.w3.org)
☐ Testado em mais de um navegador

O que NÃO fazer

❌ Usar <div> para tudo (falta semântica)
❌ Pular níveis de heading (h1 → h3)
❌ Esquecer alt nas imagens
❌ Usar <br> para espaçamento (use margin/padding no CSS)
❌ Estilos inline (style="...") em excesso
❌ Tags obsoletas: <font>, <center>, <b> (prefira <strong>)
❌ Esquecer o lang no <html>
❌ Conteúdo sem heading (texto solto sem <h1>-<h6>)

HTML vs CSS vs JS — papéis claros

HTML  → Estrutura e conteúdo (o que aparece)
CSS   → Aparência e layout (como aparece)
JS    → Comportamento e interação (o que faz)

📌 Mantenha cada um separado:
  - HTML sem estilos inline
  - CSS sem JS embutido
  - JS sem HTML dentro de strings
🧩 Resumo visual:
HTML
Estrutura
CSS
Estilo
JS
Interação
📌 Regra de ouro: HTML deve ser como uma escultura — cada tag tem um propósito. Se nenhuma tag semântica servir, use uma <div> ou <span>. Mas primeiro pergunte: "existe uma tag HTML para isso?"
