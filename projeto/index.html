01. Estrutura HTML

O esqueleto da página

Crie um arquivo index.html com esta estrutura inicial:

<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width"> <title>Meu Portfólio</title> <link rel="stylesheet" href="style.css"> </head> <body> <header> <nav> <a href="#">Início</a> <a href="#sobre">Sobre</a> <a href="#projetos">Projetos</a> <a href="#contato">Contato</a> </nav> </header> <main> <section id="hero"> <h1>Olá, eu sou <span>João</span></h1> <p>Desenvolvedor web em formação</p> </section> <section id="sobre"> <h2>Sobre Mim</h2> <p>Texto sobre você...</p> </section> <section id="projetos"> <h2>Meus Projetos</h2> <div class="grid"> <article class="card">Projeto 1</article> <article class="card">Projeto 2</article> <article class="card">Projeto 3</article> </div> </section> <section id="contato"> <h2>Contato</h2> <form> <input type="text" placeholder="Seu nome"> <input type="email" placeholder="Seu email"> <button type="submit">Enviar</button> </form> </section> </main> <footer> <p>© 2024 João. Feito com HTML, CSS e JS.</p> </footer> <script src="script.js"></script> </body> </html>
🧠 O que aprendemos aqui: Usamos tags semânticas (<header>, <main>, <section>, <footer>), navegação com <nav>, e organizamos o conteúdo em seções claras.

02. Estilo CSS

Dando vida à estrutura

Crie style.css na mesma pasta e adicione:

* { margin: 0; padding: 0; box-sizing: border-box; } body { font-family: 'Segoe UI', sans-serif; background: #0b0d14; color: #e8e4de; line-height: 1.6; } /* NAVEGAÇÃO */ header { position: fixed; top: 0; width: 100%; background: rgba(11, 13, 20, 0.9); padding: 16px 24px; border-bottom: 1px solid #242a36; } nav { max-width: 960px; margin: 0 auto; display: flex; gap: 24px; justify-content: center; } nav a { color: #8f959e; text-decoration: none; font-weight: 500; transition: color 0.2s; } nav a:hover { color: #d4923a; } /* HERO */ #hero { text-align: center; padding: 120px 20px 60px; } #hero h1 { font-size: 2.5rem; margin-bottom: 8px; } #hero h1 span { color: #d4923a; } /* SEÇÕES */ section { max-width: 960px; margin: 0 auto; padding: 60px 20px; } h2 { font-size: 1.8rem; margin-bottom: 24px; color: #d4923a; } /* GRID DE PROJETOS */ .grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 16px; } .card { background: #141820; border: 1px solid #242a36; border-radius: 8px; padding: 40px 20px; text-align: center; transition: transform 0.3s; cursor: pointer; } .card:hover { transform: translateY(-4px); border-color: #d4923a; } /* FORMULÁRIO */ form { display: flex; flex-direction: column; gap: 12px; max-width: 400px; } input { padding: 12px; border: 1px solid #242a36; border-radius: 6px; background: #141820; color: #e8e4de; font-size: 1rem; } button { padding: 12px; background: #d4923a; color: #0b0d14; border: none; border-radius: 6px; font-weight: 600; font-size: 1rem; cursor: pointer; transition: background 0.2s; } button:hover { background: #e0a34a; } /* FOOTER */ footer { text-align: center; padding: 24px; border-top: 1px solid #242a36; color: #5c6270; font-size: 0.875rem; }
🧠 O que aprendemos aqui: Reset CSS, layout com Flexbox e Grid, cards com hover, formulário estilizado, e como organizar o CSS por seções.

03. Interatividade com JavaScript

Adicionando comportamento à página

Crie script.js na mesma pasta:

// Espera o HTML carregar document.addEventListener('DOMContentLoaded', function () { // ── 1. Smooth scroll nos links do menu ── const links = document.querySelectorAll('nav a'); links.forEach(link => { link.addEventListener('click', function (e) { e.preventDefault(); const target = document.querySelector(this.getAttribute('href')); if (target) { target.scrollIntoView({ behavior: 'smooth' }); } }); }); // ── 2. Cards: clique mostra alerta com nome ── const cards = document.querySelectorAll('.card'); cards.forEach((card, index) => { card.addEventListener('click', function () { alert(`Você clicou no Projeto ${index + 1}`); }); }); // ── 3. Formulário: feedback sem recarregar ── const form = document.querySelector('form'); if (form) { form.addEventListener('submit', function (e) { e.preventDefault(); alert('Mensagem enviada com sucesso! (simulação)'); form.reset(); }); } });
🧠 O que aprendemos aqui: Event listeners, scrollIntoView para navegação suave, manipulação do DOM, e como prevenir o comportamento padrão de formulários com preventDefault().

05. Desafios para evoluir

Aumente a complexidade aos poucos e consolide cada conceito

Nível 1 — Fundamentos

✅ Personalize as cores e fontes
✅ Troque o texto de "João Dev" pelo seu nome
✅ Adicione uma seção "Habilidades" com barras de progresso
✅ Deixe o header com fundo transparente no topo
✅ Adicione uma imagem de perfil (foto sua ou avatar)

Nível 2 — Interação

✅ Formulário que mostra a mensagem na tela (sem alert)
✅ Cards de projeto que abrem um modal com detalhes
✅ Smooth scroll + destaque do link ativo no menu (scrollspy)
✅ Botão "voltar ao topo" que aparece ao rolar
✅ Validação do formulário com mensagens de erro
✅ Modo claro/escuro com botão (use localStorage!)

Nível 3 — Profissional

✅ Salvar os projetos num array de objetos e renderizar com JS
✅ Filtrar projetos por categoria (JS, CSS, etc.)
✅ Animações ao rolar (IntersectionObserver)
✅ Deploy no GitHub Pages (veja a página de Ferramentas)
✅ Adicionar uma página "Sobre" com rota (ou mudar o conteúdo via JS)
