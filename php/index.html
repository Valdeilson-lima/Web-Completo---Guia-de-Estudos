01. Introdução ao PHP

A linguagem que roda no servidor

O que é PHP?

PHP (sigla de PHP: Hypertext Preprocessor) é uma linguagem de script server-side (lado do servidor), usada principalmente para desenvolvimento web. Ela é executada no servidor e o resultado — geralmente HTML — é enviado ao navegador do usuário.

Cliente vs servidor

Navegador (cliente)          Servidor (PHP)
      │                            │
      │──── requisição ───────────▶│  executa o PHP
      │     GET /index.php         │  consulta MySQL, arquivos...
      │                            │
      │◀──── resposta (HTML) ──────│  echo/print geram o HTML
ℹ️ Importante: o navegador nunca vê o código PHP — apenas o HTML final. Por isso o PHP pode acessar banco de dados e arquivos do servidor com segurança.

Características principais

  • Código aberto e gratuito;
  • Fácil integração com HTML;
  • Ampla utilização com bancos de dados (MySQL);
  • Suporta programação procedural e orientada a objetos;
  • Sintaxe flexível e tolerante.

Instalando o ambiente

# Opção 1 — servidor embutido (a partir do PHP 7.4)
php -S localhost:8000

# Opção 2 — pacotes completos (Apache + MySQL + PHP)
# XAMPP, WAMP, MAMP ou Laragon

# Conferir a versão instalada
php -v

Estrutura básica de um arquivo PHP

<?php
echo "Olá, mundo!";
?>

<!-- Também é válido omitir a tag de fechamento -->
<?php
echo "Sem a tag de fechamento";
Olá, mundo!

echo, print e comentários

<?php
// Comentário de uma linha
# Outro estilo de comentário de uma linha

/* Comentário
   de várias linhas */

echo "Olá";        // Não retorna valor (mais rápido)
print "Olá";       // Retorna 1 (usável em expressões)

echo "PHP", " é ", "legal";   // echo aceita vários argumentos

// Misturando com HTML
?> 
<h1><?php echo "Título dinâmico"; ?></h1>
<?php
💡 Dica: misture PHP e HTML com moderação. O modo template acima (?> … <?php) é muito usado em arquivos de view, mas quebre o código em arquivos separados quando a lógica crescer.

02. Variáveis & Tipos de Dados

Onde os dados ficam guardados

Declaração de variáveis

<?php
$nome = "João";        // toda variável começa com $
$idade = 30;
$altura = 1.75;
$ativo = true;

// Variáveis são case-sensitive
$Nome = "Maria";       // é diferente de $nome

// Interpolação simples
echo "Olá, $nome";
⚠️ Atenção: no PHP não é preciso declarar o tipo — ele é inferido pelo valor. Mesmo assim, atribuir o tipo certo evita bugs silenciosos. Use nomes descritivos e camelCase para variáveis.

Tipos de dados

Tipo Descrição Exemplo
string Texto "Olá"
int Número inteiro 42
float Número decimal 1.75
bool Verdadeiro ou falso true
array Lista de valores [1, 2, 3]
object Instância de classe new Fruta()
null Sem valor null

Inspecionando variáveis

<?php
$nome = "João";
$idade = 30;

echo gettype($nome);      // string
var_dump($idade);         // int(30)
print_r([1, 2, 3]);       // exibe arrays legíveis

// Verificações de tipo
is_string($nome);         // true
is_int($idade);           // true
isset($nome);             // true (existe e não é null)
empty("");                // true  (vazio ou falso)
empty(0);                 // true
empty("0");               // true  (!)
empty([]);                // true

Conversão de tipos (casting)

<?php
$texto = "123";

(int) $texto;      // 123
(float) $texto;    // 123.0
(string) 123;      // "123"
(bool) 0;          // false
(array) "abc";     // ["abc"]

// Funções equivalentes
intval("42");      // 42
floatval("3.14");  // 3.14
strval(42);        // "42"

// PHP 8+ — conversões mais seguras
// intdiv(10, 3);  // 3

Variáveis variáveis (bônus)

<?php
$nome = "cidade";
$$nome = "Recife";   // cria $cidade = "Recife"

echo $cidade;        // Recife

03. Operadores & Constantes

Cálculos, comparações e valores imutáveis

Operadores aritméticos

<?php
$a = 10;
$b = 3;

$a + $b;    // 13  (soma)
$a - $b;    // 7   (subtração)
$a * $b;    // 30  (multiplicação)
$a / $b;    // 3.333... (divisão — sempre float)
$a % $b;    // 1   (resto / módulo)
$a ** $b;   // 1000 (exponenciação)

intdiv($a, $b);   // 3 (divisão inteira)

// Incremento / decremento
$n = 5;
$n++;       // 6
$n--;       // 5
++$n;       // 6 (pré-incremento)
$n--;       // 5

Atribuição

<?php
$x = 10;

$x += 5;    // $x = 15
$x -= 3;    // $x = 12
$x *= 2;    // $x = 24
$x /= 4;    // $x = 6
$x %= 4;    // $x = 2
$x **= 3;   // $x = 8
$x ??= 99;  // atribui se for null

$texto  = "Olá";
$texto .= ", João";   // concatena → "Olá, João"

Comparação

<?php
5 ==  "5";   // true  (igual — compara só o valor)
5 === "5";   // false (idêntico — valor E tipo)
5 !=  "5";   // false
5 !== "5";   // true

10 > 5;      // true
10 < 5;      // false
10 >= 10;    // true
10 <= 5;     // false

// Operador "spaceship" (PHP 7+) — retorna -1, 0 ou 1
1 <=> 2;     // -1
2 <=> 2;     //  0
3 <=> 2;     //  1
🚨 Cuidado: sempre prefira === e !==. Com == o PHP converte tipos, e casos como 0 == "abc" mudaram de comportamento entre versões — uma fonte clássica de bugs.

Operadores lógicos

<?php
// AND — todas precisam ser true
true && true;    // true
true and false;  // false (and tem precedência menor que &&)

// OR — pelo menos uma true
true || false;   // true
false or false;  // false

// NOT
!true;           // false

// XOR — exatamente uma verdadeira
true xor false;  // true

Coalescência e ternário

<?php
$nome = $_GET["nome"] ?? "Visitante";   // null coalescing (PHP 7+)

// Ternário
$status = $idade >= 18 ? "Maior" : "Menor";

// Ternário curto (Elvis) — usa o próprio valor se verdadeiro
$login = $usuario ?: "anônimo";

Constantes

<?php
// Forma antiga (global)
define("PI", 3.14159);
define("APP_NOME", "Meu App");

// Forma moderna (recomendada) — escopo de namespace
const TAXA = 0.15;

echo PI;               // 3.14159
echo TAXA;             // 0.15

// Constantes mágicas
echo __FILE__;         // caminho do arquivo
echo __DIR__;          // diretório do arquivo
echo __LINE__;         // linha atual
💡 Dica: use const por padrão e define() só quando precisar definir dentro de uma condição ou com valor calculado em tempo de execução.

04. Strings & Concatenação

Aspas simples, duplas e interpolação

Aspas simples vs aspas duplas

<?php
$nome = "João";

// Aspas simples — texto literal, NÃO interpola
echo 'Olá, $nome';   // Olá, $nome

// Aspas duplas — interpola variáveis
echo "Olá, $nome";   // Olá, João
💡 Dica: sem variáveis, prefira aspas simples — são ligeiramente mais rápidas, pois o PHP não precisa analisar a string.

Interpolação complexa com chaves

<?php
$usuario = ["nome" => "João"];

// ERRADO — gera erro de parse
echo "Nome: $usuario['nome']";

// CORRETO — use chaves { }
echo "Nome: {$usuario['nome']}";

// Também funciona com objetos e métodos
echo "Total: R$ {$carrinho->getTotal()}";

Heredoc e Nowdoc

<?php
$nome = "João";

// Heredoc — interpola (como aspas duplas)
$texto = <<<EOT
Olá, $nome!
Bem-vindo ao sistema.
EOT;

// Nowdoc — não interpola (como aspas simples)
$literal = <<<'EOT'
Olá, $nome! (não interpola)
EOT;

Concatenação

<?php
$nome = "João";
$sobrenome = "Silva";

// Operador: ponto (.)
$nomeCompleto = $nome . " " . $sobrenome;
echo $nomeCompleto;            // João Silva

// Atribuição com concatenação (.=)
$mensagem  = "Olá";
$mensagem .= ", João";
$mensagem .= "! Bem-vindo.";
echo $mensagem;                // Olá, João! Bem-vindo.

Interpolação ou concatenação?

<?php
// Concatenação
echo "Olá, " . $nome . "! Você tem " . $idade . " anos.";

// Interpolação (mais legível)
echo "Olá, $nome! Você tem $idade anos.";
💡 Recomendação: use interpolação em strings simples e concatenação quando precisar combinar funções, arrays ou objetos complexos.

$s = "  Programar em PHP é divertido  ";

$frase = "Aprendendo PHP moderno";

str_starts_with($frase, "Aprend");  // true
str_ends_with($frase, "moderno");   // true

Códigos de formatação (sprintf / printf)

Código Tipo

%x Hexadecimal

06. Arrays

Uma variável que guarda vários valores

O que é um array?

Um array armazena múltiplos valores. No PHP existem dois tipos principais: indexados (chaves numéricas 0, 1, 2…) e associativos (chaves em texto), vistos no próximo tópico.

Arrays indexados

<?php
// Sintaxe antiga
$frutas = array("Maçã", "Banana", "Laranja");

// Sintaxe moderna (recomendada, PHP 5.4+)
$frutas = ["Maçã", "Banana", "Laranja"];

// Acessando
echo $frutas[0];    // Maçã
echo $frutas[1];    // Banana

// Adicionando
$frutas[] = "Uva";              // adiciona no final
array_push($frutas, "Pera");    // também no final

// Contando
echo count($frutas);            // 5

// Último elemento
echo $frutas[count($frutas) - 1];

Arrays multidimensionais

<?php
$alunos = [
    ["nome" => "Ana",     "nota" => 9.5],
    ["nome" => "Carlos",  "nota" => 7.0],
    ["nome" => "Mariana", "nota" => 8.5],
];

echo $alunos[0]["nome"];   // Ana
echo $alunos[2]["nota"];   // 8.5

Funções essenciais de arrays

Função Descrição Exemplo
count() Conta itens count($arr)
print_r() Exibe array legível print_r($arr)
var_dump() Exibe com tipos var_dump($arr)
array_push() Adiciona no final array_push($arr, "x")
array_pop() Remove do final array_pop($arr)
array_shift() Remove do início array_shift($arr)
array_unshift() Adiciona no início array_unshift($arr, "x")
sort() / rsort() Ordena crescente / decrescente sort($arr)
in_array() Verifica se valor existe in_array("x", $arr)
array_keys() Retorna só as chaves array_keys($arr)
array_values() Retorna só os valores array_values($arr)

Percorrendo com foreach

<?php
$frutas = ["Maçã", "Banana", "Laranja"];

// Indexado
foreach ($frutas as $fruta) {
    echo $fruta . "<br>";
}

// Com a chave
foreach ($frutas as $indice => $fruta) {
    echo "$indice: $fruta <br>";
}

// foreach por referência (permite modificar)
foreach ($frutas as &$fruta) {
    $fruta = strtoupper($fruta);
}
unset($fruta);   // sempre "quebre" a referência ao final
💡 Dica: print_r() é ótimo para depurar durante o desenvolvimento. Em produção, nunca deixe saídas de depuração no código.

07. Arrays Associativos

Chaves em texto — como um objeto em outras linguagens

Sintaxe

<?php
$usuario = [
    "nome"  => "João",
    "idade" => 30,
    "email" => "joao@email.com",
];

echo $usuario["nome"];    // João

Destrinchando

  • $usuario → variável (toda variável PHP começa com $);
  • [ ... ] → define o array (sintaxe moderna 5.4+);
  • "nome" → chave (key);
  • => → operador de associação;
  • "João" → valor (value).

Lendo, escrevendo e verificando

<?php
$usuario["idade"] = 31;              // altera
$usuario["telefone"] = "1199999";    // adiciona
unset($usuario["email"]);            // remove

// Verificações
isset($usuario["nome"]);             // true (existe e não é null)
array_key_exists("nome", $usuario); // true
in_array(31, $usuario);              // true (procura valor)

// Percorrendo
foreach ($usuario as $chave => $valor) {
    echo "$chave: $valor <br>";
}

Comparação com outras linguagens

O array associativo do PHP equivale a estruturas diferentes em cada linguagem: 

// JavaScript — Objeto
let usuario = { nome: "João", idade: 30 };
console.log(usuario.nome);

// Python — Dicionário
usuario = { "nome": "João", "idade": 30 }
print(usuario["nome"])

// Java — HashMap
HashMap<String, String> usuario = new HashMap<>();
usuario.put("nome", "João");
System.out.println(usuario.get("nome"));

// C# — Dictionary
var usuario = new Dictionary<string, string> {
    { "nome", "João" }
};
Console.WriteLine(usuario["nome"]);

// Ruby — Hash
usuario = { "nome" => "João" }
puts usuario["nome"]
Linguagem Nome Símbolo Acesso Tipo obrigatório?
PHP Array Associativo => $arr["chave"] Não
JavaScript Objeto : obj.chave Não
Python Dicionário : dict["chave"] Não
Java HashMap .put() map.get("chave") Sim
C# Dictionary { } dict["chave"] Sim
Ruby Hash => hash["chave"] Não
⚠️ Curiosidade: o PHP permite misturar índices numéricos e strings no mesmo array — algo incomum em outras linguagens. 
<?php
$dados = [
    0       => "Primeiro",
    "nome"  => "João",
    1       => 30,
    "ativo" => true,
];

Ordenação e transformação (avançado)

<?php
$notas = ["Ana" => 9.5, "Carlos" => 7.0, "Mariana" => 8.5];

sort($notas);    // ordena pelos VALORES (perde as chaves)
asort($notas);   // ordena pelos valores mantendo as chaves
ksort($notas);   // ordena pelas chaves
arsort($notas);  // valores, decrescente, mantendo chaves

// Transformações funcionais
$dobrados = array_map(fn ($n) => $n * 2, [1, 2, 3]);   // [2,4,6]
$pares    = array_filter([1, 2, 3, 4], fn ($n) => $n % 2 === 0);
$soma     = array_reduce([1, 2, 3], fn ($acc, $n) => $acc + $n, 0);

// Ordenação customizada
usort($alunos, fn ($a, $b) => $b["nota"] <=> $a["nota"]);

08. Controle de Fluxo

Condicionais e laços

if / elseif / else

<?php
$idade = 20;

if ($idade < 12) {
    echo "Criança";
} elseif ($idade < 18) {
    echo "Adolescente";
} elseif ($idade < 60) {
    echo "Adulto";
} else {
    echo "Idoso";
}

Sintaxe alternativa (útil em templates)

<?php if ($logado): ?>
    <p>Bem-vindo!</p>
<?php else: ?>
    <p>Faça login.</p>
<?php endif; ?>

switch

<?php
$dia = "seg";

switch ($dia) {
    case "sab":
    case "dom":
        echo "Fim de semana";
        break;
    case "seg":
        echo "Começo da semana";
        break;
    default:
        echo "Dia comum";
}

while / do-while

<?php
// while — testa antes
$i = 0;
while ($i < 5) {
    echo $i;
    $i++;
}

// do-while — executa pelo menos uma vez
$j = 0;
do {
    echo $j;
    $j++;
} while ($j < 5);

for / foreach

<?php
// for clássico
for ($i = 0; $i < 10; $i++) {
    echo $i;
}

// foreach com arrays (preferido)
foreach ([1, 2, 3] as $numero) {
    echo $numero;
}

break e continue

<?php
foreach (range(1, 10) as $n) {
    if ($n === 3) {
        continue;   // pula o 3
    }
    if ($n === 6) {
        break;      // para no 6
    }
    echo $n;
}

match (PHP 8+) — o irmão moderno do switch

<?php
$status = match ($codigo) {
    200, 201 => "Sucesso",
    404      => "Não encontrado",
    500      => "Erro no servidor",
    default  => "Desconhecido",
};

// match compara com === e retorna um valor
💡 Dica: prefira match a switch quando só precisar mapear valor → resultado. É mais seguro pois usa comparação estrita e não exige break.

09. Funções

Blocos de código reutilizáveis

Declaração básica

<?php
function saudacao($nome) {
    return "Olá, $nome!";
}

echo saudacao("João");   // Olá, João!

Parâmetros com valor padrão

<?php
function somar($a, $b = 10) {
    return $a + $b;
}

somar(5);        // 15
somar(5, 2);     // 7

Declarações de tipo (PHP 7+)

<?php
// Tipos nos parâmetros e no retorno
function calcularTotal(float $preco, int $qtd): float {
    return $preco * $qtd;
}

// Nullable (? antes do tipo)
function buscar(int $id): ?array {
    return $id > 0 ? ["id" => $id] : null;
}

// Tipos união (PHP 8+)
function formatar(int|float $valor): string {
    return number_format($valor, 2, ",", ".");
}

Argumentos variádicos

<?php
function somarTodos(int ...$numeros): int {
    return array_sum($numeros);
}

somarTodos(1, 2, 3, 4);   // 10

// Desempacotando um array com ...
$valores = [1, 2, 3];
somarTodos(...$valores);  // 6

Passagem por referência

<?php
function dobrar(&$numero) {
    $numero *= 2;
}

$x = 5;
dobrar($x);
echo $x;   // 10 (o valor original mudou)

Escopo

<?php
$global = "acessível fora";

function teste() {
    // Variáveis de fora NÃO entram automaticamente
    global $global;            // forma explícita
    echo $global;

    $local = "só aqui dentro";

    // static mantém o valor entre chamadas
    static $contador = 0;
    $contador++;
    return $contador;
}

echo teste();   // 1
echo teste();   // 2

Arrow functions e closures (PHP 7.4+)

<?php
$multiplicador = 3;

// Closure — precisa de use para capturar variáveis
$fn1 = function ($n) use ($multiplicador) {
    return $n * $multiplicador;
};

// Arrow function — captura automaticamente
$fn2 = fn ($n) => $n * $multiplicador;

echo $fn2(5);   // 15

// Muito usadas com array_map / array_filter
$nomes = array_map(fn ($n) => strtoupper($n), ["ana", "joão"]);
💡 Dica: funções devem fazer uma coisa e ter um nome que diga o que fazem. Se o nome precisa de "e", provavelmente são duas funções.

10. Includes & Namespaces

Organizando o projeto em vários arquivos

include vs require

<?php
// include — gera AVISO se o arquivo não existir; o script continua
include "header.php";
include_once "header.php";   // só inclui uma vez

// require — gera ERRO FATAL se não existir; o script para
require "config.php";
require_once "config.php";   // recomendado para classes/funções

// Caminho absoluto com __DIR__ (evita problemas de diretório atual)
require __DIR__ . "/config/config.php";
Comando Se o arquivo não existir
include Warning — o script continua
require Fatal error — o script para
include_once Warning + impede inclusão duplicada
require_once Fatal error + impede inclusão duplicada

Estrutura típica de projeto

meu-projeto/
├── index.php
├── config/
│   └── database.php
├── src/
│   ├── Models/
│   │   └── Usuario.php
│   └── Repositories/
│       └── UsuarioRepository.php
├── views/
│   ├── header.php
│   └── footer.php
└── public/
    └── assets/

Namespaces

<?php
// src/Models/Usuario.php
namespace App\Models;

class Usuario
{
    public function nome(): string
    {
        return "João";
    }
}
<?php
// index.php
require __DIR__ . "/src/Models/Usuario.php";

use App\Models\Usuario;

$u = new Usuario();
echo $u->nome();

// Ou com o caminho completo

12. Classes e Objetos

O molde e as instâncias — o coração da POO

Conceitos

  • Classe: o "molde" ou "planta" que define características (propriedades) e comportamentos (métodos).
  • Objeto: uma instância concreta criada a partir da classe.

Exemplo de classe

<?php
class Fruta
{
    // Propriedades
    public $nome;
    public $cor;

    // Métodos
    public function setNome($nome)
    {
        $this->nome = $nome;
    }

    public function getNome()
    {
        return $this->nome;
    }
}

Criando e usando um objeto

<?php
$melancia = new Fruta();
$melancia->setNome("Melancia");
$melancia->cor = "Verde";

echo $melancia->getNome();   // Melancia

Entendendo a seta ( -> )

A seta -> é o operador de acesso do PHP. Ela serve para acessar propriedades e métodos de um objeto:

  • $this → refere-se ao próprio objeto dentro da classe;
  • $objeto->metodo() → chama um método do objeto;
  • $objeto->propriedade → acessa uma propriedade do objeto.
💡 Fluxo lógico: (1) a classe Fruta define que frutas têm nome e sabem configurar/pegar o nome; (2) o objeto $melancia é criado a partir da classe; (3) a ação $melancia->setNome(...) altera os dados daquele objeto específico.

Construtor e visibilidade

<?php
class Produto
{
    private float $preco;         // só a própria classe acessa
    protected string $nome;       // classe + classes filhas
    public int $estoque = 0;      // acessível por qualquer um

    public function __construct(string $nome, float $preco)
    {
        $this->nome  = $nome;
        $this->preco = $preco;
    }

    public function getPreco(): float
    {
        return $this->preco;
    }

    public function setPreco(float $preco): void
    {
        if ($preco < 0) {
            throw new InvalidArgumentException("Preço inválido");
        }
        $this->preco = $preco;
    }
}

$p = new Produto("Teclado", 150.0);
echo $p->getPreco();

Propriedades e métodos estáticos

<?php
class Conversor
{
    public const TAXA = 5.5;

    public static function dolarParaReal(float $valor): float
    {
        return $valor * self::TAXA;
    }
}

// Não precisa instanciar
echo Conversor::dolarParaReal(10);   // 55
⚠️ Encapsulamento: deixe propriedades private e exponha apenas o necessário por métodos. Isso impede que o estado do objeto seja corrompido de fora.

Herança, abstração, interfaces, traits e polimorfismo

Herança (extends)

<?php
class Animal
{
    public function __construct(protected string $nome) {}

    public function falar(): string
    {
        return "$this->nome faz um som";
    }
}

class Cachorro extends Animal
{
    public function falar(): string
    {
        return "$this->nome late";     // sobrescreve o método
    }

    public function buscar(): string
    {
        return "$this->nome buscou a bolinha";
    }

parent:: e chamada do construtor

<?php
class Gato extends Animal
{
    public function __construct(string $nome, private string $cor)
    {
        parent::__construct($nome);   // reaproveita o construtor pai
    }

    public function falar(): string
    {
        return parent::falar() . " (mia)";
    }
}

Classes abstratas

<?php
abstract class Forma
{
    // Método abstrato: obriga as filhas a implementar
    abstract public function area(): float;

    // Método concreto: já pronto para reuso
    public function descricao(): string
    {
        return "Área: " . number_format($this->area(), 2, ",", ".");
    }
}

class Circulo extends Forma
{
    public function __construct(private float $raio) {}

    public function area(): float
    {
        return 3.14159 * $this->raio ** 2;
    }
}

// new Forma();     // ❌ erro: classe abstrata não instancia
echo (new Circulo(2))->descricao();

Interfaces

<?php
interface Pagavel
{
    public function pagar(float $valor): bool;
}

class CartaoCredito implements Pagavel
{
    public function pagar(float $valor): bool
    {
        return true;   // lógica real aqui
    }
}

class Pix implements Pagavel
{
    public function pagar(float $valor): bool
    {
        return true;
    }
}

Traits — reuso de código

<?php
trait Loggable
{
    public function log(string $msg): void
    {
        echo "[" . date("H:i:s") . "] $msg";
    }
}

class Usuario
{
    use Loggable;    // "cola" os métodos do trait na classe
}

(new Usuario())->log("Login efetuado");
Recurso Serve para
Herança (extends) Especializar uma classe ("é um tipo de")
Classe abstrata Base parcial que não pode ser instanciada
Interface Contrato de métodos ("sabe fazer")
Trait Reuso de métodos sem herança múltipla

Polimorfismo

<?php
function cobrar(Pagavel $metodo, float $valor): void
{
    $metodo->pagar($valor);   // funciona com QUALQUER implementação
}

cobrar(new Pix(), 100);
cobrar(new CartaoCredito(), 100);
💡 Dica: programe para interfaces, não para implementações. Assim você troca a forma de pagamento sem mudar quem cobra.

15. Erros & Exceções

Tratando o que dá errado com elegância

Níveis de erro

Nível Significado
E_WARNING Aviso — o script continua
E_NOTICE Observação (ex.: variável não definida)
E_ERROR Erro fatal — o script para
E_ALL Todos os erros e avisos 
<?php
// Durante o desenvolvimento, mostre tudo
error_reporting(E_ALL);

// Em produção, esconda e registre em log
ini_set("display_errors", "0");

try / catch / finally

<?php
function dividir(float $a, float $b): float
{
    if ($b === 0.0) {
        throw new InvalidArgumentException("Divisão por zero");
    }
    return $a / $b;
}

try {
    echo dividir(10, 0);
} catch (InvalidArgumentException $e) {
    echo "Erro: " . $e->getMessage();
} catch (Throwable $e) {
    echo "Erro inesperado";
} finally {
    echo "Sempre executa";   // aconteça o que acontecer
}

Exceções personalizadas

<?php
class EstoqueInsuficienteException extends Exception {}

class Produto
{
    public function __construct(private int $estoque) {}

    public function vender(int $qtd): void
    {
        if ($qtd > $this->estoque) {
            throw new EstoqueInsuficienteException(
                "Só há {$this->estoque} unidades"
            );
        }
        $this->estoque -= $qtd;
    }
}

try {
    (new Produto(3))->vender(5);
} catch (EstoqueInsuficienteException $e) {
    echo $e->getMessage();   // Só há 3 unidades
}
💡 Dica: exceções são para situações excepcionais. Para validação previsível de formulário, prefira retornar valores/erros. Nunca use catch vazio — engolir erros esconde bugs.

16. Sessões, Cookies & Uploads

Mantendo estado entre requisições

Sessões

<?php
// SEMPRE antes de qualquer saída HTML
session_start();

// Guardando dados
$_SESSION["usuario_id"] = 42;
$_SESSION["nome"] = "João";

// Lendo
if (isset($_SESSION["usuario_id"])) {
    echo "Logado como " . $_SESSION["nome"];
}

// Encerrando
unset($_SESSION["nome"]);     // remove uma chave

Cookies

<?php
// setcookie(nome, valor, expira, caminho, domínio, seguro, httpOnly)
setcookie("tema", "escuro", time() + 60 * 60 * 24 * 30, "/");

// Lendo
echo $_COOKIE["tema"] ?? "claro";

// Removendo (expira no passado)
setcookie("tema", "", time() - 3600, "/");
⚠️ Sessão vs Cookie: a sessão guarda os dados no servidor (o navegador só recebe um ID); o cookie guarda os dados no navegador. Por isso nunca coloque senhas ou dados sensíveis em cookies.

Upload de arquivos

<!-- form precisa de enctype -->
<form action="upload.php" method="post" enctype="multipart/form-data">
    <input type="file" name="arquivo" />
    <button type="submit">Enviar</button>
</form>
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {

    $arquivo = $_FILES["arquivo"];

    if ($arquivo["error"] !== UPLOAD_ERR_OK) {
        exit("Falha no upload");
    }

    // 1. Valide o tipo pelo conteúdo, não pela extensão
    $permitidos = ["image/jpeg", "image/png", "image/webp"];
    $tipo = mime_content_type($arquivo["tmp_name"]);

    if (!in_array($tipo, $permitidos, true)) {
        exit("Tipo não permitido");
    }

    // 2. Limite de tamanho
    if ($arquivo["size"] > 2 * 1024 * 1024) {   // 2 MB
        exit("Arquivo muito grande");
    }

    // 3. Gere um nome seguro (nunca confie no nome original)
    $extensao = pathinfo($arquivo["name"], PATHINFO_EXTENSION);
    $novoNome = bin2hex(random_bytes(16)) . "." . $extensao;

    // 4. Mova para fora da raiz pública, se possível
    move_uploaded_file($arquivo["tmp_name"], __DIR__ . "/uploads/" . $novoNome);
}
🚨 Segurança: aceitar upload sem validar é uma das falhas mais exploradas. Nunca execute o arquivo enviado, valide o MIME real e guarde fora do diretório público.

17. Banco de Dados com PDO

Falando com o MySQL com segurança

Conectando

<?php
$dsn = "mysql:host=localhost;dbname=loja;charset=utf8mb4";

$opcoes = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
];

try {
    $pdo = new PDO($dsn, "root", "senha", $opcoes);
} catch (PDOException $e) {
    exit("Erro de conexão: " . $e->getMessage());
}

Prepared statements (evita SQL Injection)

<?php
// ❌ NUNCA faça isso — abre porta para SQL Injection
// $sql = "SELECT * FROM usuarios WHERE email = '$email'";

// ✅ Use placeholders nomeados
$sql = "SELECT * FROM usuarios WHERE email = :email";

$stmt = $pdo->prepare($sql);
$stmt->execute(["email" => $email]);
$usuario = $stmt->fetch();

// Ou com placeholders posicionais (?)
$stmt = $pdo->prepare("SELECT * FROM produtos WHERE preco < ?");
$stmt->execute([100]);
$produtos = $stmt->fetchAll();

INSERT, UPDATE e DELETE

<?php
// INSERT
$stmt = $pdo->prepare(
    "INSERT INTO usuarios (nome, email) VALUES (:nome, :email)"
);
$stmt->execute(["nome" => "Ana", "email" => "ana@email.com"]);

$novoId = $pdo->lastInsertId();

// UPDATE
$stmt = $pdo->prepare("UPDATE usuarios SET nome = ? WHERE id = ?");
$stmt->execute(["Ana Silva", $novoId]);

// DELETE
$stmt = $pdo->prepare("DELETE FROM usuarios WHERE id = ?");
$stmt->execute([$novoId]);

// Quantas linhas mudaram
echo $stmt->rowCount();

Modos de busca (fetch)

<?php
$stmt = $pdo->query("SELECT * FROM produtos");

$stmt->fetch();              // uma linha
$stmt->fetchAll();           // todas as linhas (array)

// Uma coluna só
$total = $pdo->query("SELECT COUNT(*) FROM produtos")->fetchColumn();

Transações

<?php
try {
    $pdo->beginTransaction();

    $pdo->exec("UPDATE contas SET saldo = saldo - 100 WHERE id = 1");
    $pdo->exec("UPDATE contas SET saldo = saldo + 100 WHERE id = 2");

    $pdo->commit();          // confirma tudo
} catch (Throwable $e) {
    $pdo->rollBack();        // desfaz tudo em caso de erro
    echo "Transação cancelada";
}
💡 Dica: PDO funciona com MySQL, PostgreSQL, SQLite e outros — troque só a DSN. Sempre use prepared statements: eles separam o SQL dos dados, o que neutraliza a injeção.

19. Segurança & Boas Práticas

As falhas mais comuns e como evitá-las

As 4 ameaças clássicas

Ameaça O que é Solução
XSS Injetar script via dado do usuário htmlspecialchars() na saída
SQL Injection Injetar SQL via input Prepared statements (PDO)
CSRF Forçar ação em nome do usuário Token por formulário
Senhas fracas Guardar senha em texto puro password_hash()

XSS — escapando a saída

<?php
// ❌ perigoso: se $nome contiver <script>, ele executa

// ✅ escape sempre na SAÍDA
echo "Olá, " . htmlspecialchars($nome, ENT_QUOTES, "UTF-8");

// Ao cadastrar

// Ao fazer login

    echo "Login OK";
}

// Rehash quando o algoritmo padrão evoluir
if (password_needs_rehash($hashDoBanco, PASSWORD_DEFAULT)) {
    // gere e salve um novo hash
}

<?php
session_start();

    $_SESSION["csrf"] = bin2hex(random_bytes(32));
}

// No formulário
?>
<input type="hidden" name="csrf" value="<?= $_SESSION['csrf'] ?>" />
<?php

// Na validação (POST)

    exit("Token inválido");
}

Checklist de boas práticas

  • Valide e limpe todo input;
  • Escape toda saída;
  • Use prepared statements para o banco;
  • Hash de senha com password_hash();
  • Nunca exponha display_errors em produção;
  • Configure session.cookie_httponly e session.cookie_secure;
  • Mantenha o PHP atualizado;
  • Use HTTPS sempre.
🚨 Nunca confie no cliente: validação no JavaScript é conveniência para o usuário — a validação que conta acontece no servidor, em PHP.

Uma classe com tudo: Produto + PDO

<?php
declare(strict_types=1);

class ProdutoRepository
{
    public function __construct(private PDO $pdo) {}

    public function buscar(int $id): ?array
    {
        $stmt = $this->pdo->prepare(
            "SELECT * FROM produtos WHERE id = ?"
        );
        $stmt->execute([$id]);
        return $stmt->fetch() ?: null;
    }

    public function criar(string $nome, float $preco): int
    {
        $stmt = $this->pdo->prepare(
            "INSERT INTO produtos (nome, preco) VALUES (?, ?)"
        );
        $stmt->execute([$nome, $preco]);
        return (int) $this->pdo->lastInsertId();
    }

    public function listar(): array
    {
        return $this->pdo
            ->query("SELECT * FROM produtos ORDER BY nome")
            ->fetchAll();
    }
}
