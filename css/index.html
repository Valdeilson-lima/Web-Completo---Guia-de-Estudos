01. Seletores

Como "mirar" nos elementos certos

Seletores básicos

/* Elemento / Tag */
div   { ... }
p     { ... }

/* Classe */
.minha-classe { ... }

/* ID */
#meu-id { ... }

/* Universal */
* { box-sizing: border-box; }

Combinadores

/* Filho direto */
.pai > .filho { ... }

/* Descendente (qualquer profundidade) */
.avô .neto { ... }

/* Irmão adjacente (imediatamente depois) */
.irmao1 + .irmao2 { ... }

/* Irmão geral (qualquer depois) */
.irmao1 ~ .irmao2 { ... }

Seletores de atributo

[disabled]          { ... }  /* tem o atributo */
[type="text"]       { ... }  /* igual a */
[href^="https"]     { ... }  /* começa com */
[src$=".jpg"]       { ... }  /* termina com */
[class*="btn"]      { ... }  /* contém */
🧠 Dica: Prefira usar classes em vez de IDs ou tags. Classes são reutilizáveis e têm menos problemas de especificidade.

02. Box Model

Todo elemento HTML é uma caixa — entenda suas camadas

O Box Model define como o tamanho e o espaçamento de um elemento são calculados. São 4 camadas, de dentro para fora:

MARGIN (espaço externo)
BORDER (contorno)
PADDING (espaço interno)
CONTEÚDO (width / height)

Propriedades

/* PADDING */
padding: 20px;                  /* todos os lados */
padding: 10px 20px;             /* top/bottom  left/right */
padding: 10px 15px 20px 25px;   /* top right bottom left */

/* BORDER */
border: 2px solid #333;
border-radius: 8px;             /* cantos arredondados */

/* MARGIN */
margin: 20px;
margin: 10px auto;              /* centraliza horizontalmente */
margin-top: -10px;              /* valores negativos funcionam */

content-box vs border-box

/* Padrão — padding e border AUMENTAM o tamanho total */
box-sizing: content-box;
/* width: 200px + padding 20px + border 2px = 222px totais */

/* Recomendado — padding e border estão DENTRO do width declarado */
box-sizing: border-box;
/* width: 200px já inclui padding e border */
💡 Sempre use * { box-sizing: border-box; } no início do seu CSS. Isso torna o cálculo de tamanhos muito mais previsível.

03. Display

Como o elemento se comporta na página

display: block;        /* ocupa a linha inteira (div, p, h1) */
display: inline;       /* fica na mesma linha (span, a, strong) */
display: inline-block; /* inline mas aceita width/height/padding */
display: none;         /* some da tela (não ocupa espaço) */
display: flex;         /* ativa flexbox */
display: grid;         /* ativa grid */

Diferença prática

/* block */   width: 200px; → ocupa a linha toda, mas o conteúdo tem 200px
/* inline */  width/height são IGNORADOS
/* inline-block */  width/height FUNCIONAM, mas fica na mesma linha
🧠 Dica: Use display: none para esconder elementos (diferente de visibility: hidden que só os torna invisíveis mas mantém o espaço).

04. Flexbox

Layout flexível em 1 dimensão (linha ou coluna)

Container (pai)

.container {
  display: flex;
  flex-direction: row;          /* row | column | row-reverse | column-reverse */
  flex-wrap: wrap;              /* nowrap | wrap | wrap-reverse */
  justify-content: center;      /* main-axis: flex-start | center | space-between | space-around | space-evenly */
  align-items: center;          /* cross-axis: flex-start | center | stretch | baseline */
  gap: 16px;                    /* espaçamento entre os filhos */
}

Itens (filhos)

.item {
  flex: 1;                      /* cresce igualmente */
  flex-grow: 1;                 /* fator de crescimento */
  flex-shrink: 1;               /* fator de encolhimento */
  flex-basis: 200px;            /* tamanho base */
  align-self: center;           /* alinhamento individual */
  order: 2;                     /* ordem de exibição */
}

09. Unidades CSS

Absolutas, relativas, viewport — quando usar cada uma 

/* Absolutas */
px   /* pixel (1px = 1/96 de polegada) */

/* Relativas à fonte */
em   /* relativo ao font-size do PAI */
rem  /* relativo ao font-size da RAIZ (html) — 1rem = 16px padrão */

/* Percentual */
%    /* relativo ao tamanho do pai */

/* Viewport */
vw   /* 1vw = 1% da largura da viewport */
vh   /* 1vh = 1% da altura da viewport */

Quando usar

/* REM é rei: use para fontes, margens, paddings */
font-size: 1rem;   padding: 1.5rem;

/* EM para componentes que escalam juntos */
.btn { font-size: 1rem; }
.btn-small { font-size: 0.8em; }

/* % para larguras relativas ao pai */
.container { width: 80%; }

/* vw/vh para seções de tela cheia */
.hero { height: 100vh; }

15. Especificidade & Cascata

Entenda qual regra "vence" quando há conflito

A cascata (Cascading)

Se duas regras têm a mesma especificidade, a última declarada vence.

Especificidade (peso dos seletores)

Ordem de prioridade (do mais fraco ao mais forte):

1. TAG / elemento      → peso baixo      ex: div, p
2. Classes, atributos  → peso médio      ex: .card, :hover
3. IDs                 → peso alto       ex: #header
4. inline style        → muito alto
5. !important          → máxima (evite!)

Cálculo = (id, classe, tag)
div           → (0, 0, 1)
.btn          → (0, 1, 0)
#header .btn  → (1, 1, 0)
⚠️ Regra de ouro: Evite !important e IDs em seletores. Use classes para tudo.

16. Funções Modernas: clamp, min, max, calc

Tipografia fluida, larguras inteligentes e cálculos sem JavaScript

calc() — faça matemática no CSS

/* Misture unidades livremente */
width: calc(100% - 40px);
height: calc(100vh - var(--header-h));
padding: calc(1rem + 2px);

/* Importante: espaços ao redor de + e - são obrigatórios */
width: calc(100% -40px);  /* ❌ quebrado */
width: calc(100% - 40px); /* ✅ correto */

min() e max() — escolha o menor/maior valor

/* min: o MENOR valor vence (nunca passa do limite) */
width: min(90%, 600px);      /* 90% ou 600px, o que for menor */

/* max: o MAIOR valor vence (nunca fica menor que o mínimo) */
font-size: max(1rem, 3vw);   /* pelo menos 1rem */

/* Ambos aceitam quantos argumentos quiser */
padding: min(2rem, 4vw);

clamp() — o "min/max em um só" (tipografia fluida)

/*
  clamp(MÍNIMO, PREFERIDO, MÁXIMO)
  A tipografia cresce com a tela, mas nunca sai dos limites
*/

font-size: clamp(1rem, 2.5vw, 2rem);
/*   ↑ mín 1rem   ↑ prefere 2.5vw   ↑ máx 2rem */

/* Uso clássico: título que escala com a viewport */
h1 {
  font-size: clamp(1.8rem, 4vw + 1rem, 3.5rem);
}
🧪 Tipografia fluida — redimensione a janela

Este texto usa clamp()

Entre 1rem e 2.5rem, crescendo com a viewport.

🧠 Dica: clamp() elimina a necessidade de vários @media só para ajustar fontes. É o padrão moderno para tipografia fluida.

17. z-index & Stacking Context

Quem fica por cima de quem — e por que às vezes o z-index "não funciona"

Básico

/* z-index só funciona em elementos POSICIONADOS
   (position: relative | absolute | fixed | sticky)
   ou em flex/grid items */

.caixa {
  position: relative;
  z-index: 10;   /* número maior = fica por cima */
}

.caixa2 {
  position: relative;
  z-index: 5;    /* fica atrás da .caixa */
}

O problema clássico do "z-index não funciona"

/* ❌ SEM position — z-index é ignorado */
.menu { z-index: 999; }        /* não faz nada! */

/* ✅ Precisa de position (ou flex/grid) */
.menu { position: relative; z-index: 999; }

Stacking Context (contexto de empilhamento)

/* Um stacking context "prende" os filhos dentro dele.
   Eles NUNCA vão sobrepor elementos de fora, por mais
   alto que seja o z-index. */

/* Cria um stacking context (além de position + z-index): */
opacity < 1
transform
filter
backdrop-filter
animation / transition com transform
will-change
mix-blend-mode
contain: paint | layout | strict
⚠️ Importante: Se um elemento com z-index: 9999 continua atrás de outro, quase sempre é porque ele está preso dentro de um stacking context criado por um ancestral (ex: um transform ou opacity).

18. Container Queries

Responsividade baseada no container — não na tela

O problema que resolvem

/* Media queries olham para a VIEWPORT inteira.
   Container queries olham para o TAMANHO DO PAI.

   → Um card dentro de uma sidebar estreita e dentro de
     um grid largo deve se adaptar ao SEU container,
     não à tela. */

/* 1. Declare o container */
.card-wrapper {
  container-type: inline-size;   /* observa a largura */
  /* container-name: cards;      (opcional, nomeado) */
}

/* 2. Consulte como uma media query */
@container (min-width: 400px) {
  .card { display: grid; grid-template-columns: 1fr 2fr; }
}

/* Container nomeado */
@container cards (min-width: 600px) {
  .card__title { font-size: 2rem; }
}
🧪 Redimensione a janela — o card se adapta ao próprio container

🗂️ Card responsivo

Quando este container passa de 480px, este texto ganha um layout em duas colunas.

🧠 Dica: Container queries são ideais para componentes reutilizáveis (cards, widgets) que podem aparecer em contextos diferentes. Suporte completo desde 2023.

19. Seletores Modernos: :is, :where, :has, :nth-of

Menos repetição, mais poder, CSS mais limpo

:is() — agrupe seletores (com especificidade do mais forte)

/* Antes — repetição */
header a:hover, main a:hover, footer a:hover { color: red; }

/* Depois — agrupado */
:is(header, main, footer) a:hover { color: red; }

/* Também funciona com classes e pseudo-classes */
:is(.card, .banner) .title { font-weight: 700; }

:where() — agrupe SEM adicionar especificidade

/* Diferença crucial:
   :is()  → usa a especificidade do seletor mais forte dentro
   :where()→ especificidade SEMPRE ZERO (fácil de sobrescrever) */

/* Base com especificidade 0 */
:where(.card, .banner) .title { color: #333; }

/* Qualquer classe simples sobrescreve sem !important */
.title { color: var(--accent); }  /* ✅ vence */

:has() — o "seletor pai" (parent selector)

/* Seleciona o elemento QUE CONTÉM algo */

/* Card que contém uma imagem ganha padding extra */
.card:has(img) { padding: 0; }

/* Formulário com erro fica vermelho */
.form:has(.input-error) { border-color: red; }

/* Link que abre em nova aba ganha um ícone */
a:has(> img) { text-decoration: none; }

/* Barra de navegação "encolhida" quando o menu está aberto */
header:has(.menu.open) { height: 64px; }

20. Propriedades Lógicas & Recursos Modernos

CSS que respeita direção de texto, e outros recursos atuais

Propriedades lógicas (inline / block)

/* Em vez de pensar em "esquerda/direita", pense em
   "início/fim" — funciona para RTL (árabe, hebraico) */

/* Físicas (antigas) → Lógicas (novas) */
margin-left   → margin-inline-start
margin-right  → margin-inline-end
padding-top   → padding-block-start
padding-bottom→ padding-block-end
width         → inline-size
height        → block-size
text-align: left → text-align: start

/* Shorthands */
margin-inline: auto;    /* esquerda E direita */
padding-block: 1rem;    /* topo E base */
border-inline-start: 2px solid var(--accent);

aspect-ratio — proporção sem hacks

/* Antes: o famoso "padding-top hack" */
.thumb { position: relative; padding-top: 56.25%; }

/* Agora: nativo */
.thumb {
  aspect-ratio: 16 / 9;   /* vídeo */
  aspect-ratio: 1 / 1;    /* quadrado */
  width: 100%;
}

Outros recursos modernos que valem conhecer

/* scroll-behavior: suave */
html { scroll-behavior: smooth; }

/* scroll-margin-top: compensa header fixo em âncoras */
section { scroll-margin-top: 80px; }

/* color-mix: mistura cores (com suporte a variáveis) */
.btn { background: color-mix(in srgb, var(--accent) 70%, white); }

/* text-wrap: balance — quebra títulos com equilíbrio */
