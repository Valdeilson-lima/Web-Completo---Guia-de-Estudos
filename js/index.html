01. Introdução ao JavaScript

A linguagem que dá vida à web

O que é JavaScript?

JavaScript (JS) é a linguagem de programação da web. Com ela você controla o comportamento das páginas: resposta a cliques, validação de formulários, animações, requisições a servidores e muito mais.

Onde executar JavaScript

// 1. No navegador (console do DevTools)
console.log('Olá, mundo!');

// 2. Dentro do HTML (tag <script>)
<script>
  alert('Olá!');
</script>

// 3. Arquivo externo (recomendado)
<script src="app.js"></script>

async vs defer

<!-- async: baixa e executa assim que possível (não espera o HTML) -->
<script src="app.js" async></script>

<!-- defer: baixa em paralelo, executa só depois do HTML (recomendado) -->
<script src="app.js" defer></script>

Console do navegador

console.log('Mensagem comum');
console.warn('Aviso amarelo');
console.error('Erro vermelho');
console.table([1, 2, 3]);     // Exibe como tabela
console.time('label');         // Inicia cronômetro
console.timeEnd('label');      // Para cronômetro
🧠 Dica: Use o atalho F12 ou Ctrl+Shift+I para abrir o DevTools e testar código JS ao vivo no console.

02. Variáveis & Tipos de Dados

Onde os dados são armazenados

Declaração: var, let, const

// var — escopo de função, EVITE usar hoje em dia
var nome = 'João';

// let — escopo de bloco, pode reatribuir
let idade = 25;
idade = 26;

// const — escopo de bloco, NÃO pode reatribuir
const pi = 3.14;
// pi = 3;  // Erro!

Tipos primitivos

const nome = 'Maria';          // string
const idade = 30;              // number
const altura = 1.75;           // number (decimais usam ponto)
const isStudent = true;        // boolean
const carro = null;            // null (intencionalmente vazio)
let cidade;                    // undefined (não definido)
const id = Symbol('id');       // symbol (único)
const big = 9007199254740991n; // bigint (números muito grandes)

typeof — descobrir o tipo

typeof 'Olá';         // "string"
typeof 42;            // "number"
typeof true;          // "boolean"
typeof undefined;     // "undefined"
typeof null;          // "object" (erro histórico!)
typeof Symbol();      // "symbol"

Conversão de tipos (coerção)

// Explícita (recomendado)
Number('123');        // 123
String(123);          // "123"
Boolean(1);           // true

// Implícita (cuidado!)
'5' - 2;              // 3 (string vira number)
'5' + 2;              // "52" (number vira string!)
'5' * '2';            // 10

// Truthy / Falsy
Boolean('');           // false
Boolean(0);            // false
Boolean('texto');      // true
Boolean([]);           // true (array vazio é truthy!)
⚠️ Importante: Prefira const por padrão e só use let quando precisar reatribuir. Nunca use var em código novo.

03. Strings

Trabalhando com texto de forma eficiente

Criação e concatenação

const s1 = 'Aspas simples';
const s2 = "Aspas duplas";
const s3 = `Template literal (crase)`;

// Concatenação clássica
const msg = 'Olá, ' + nome + '!';

// Template literal (moderno)
const msg2 = `Olá, ${nome}!`;
const msg3 = `Linha 1
Linha 2`;                       // multi-linha natural

Principais métodos

'JavaScript'.length;                // 10
'Olá'.toUpperCase();                // "OLÁ"
'OLÁ'.toLowerCase();                // "olá"
'bola'.includes('ol');              // true
'JavaScript'.indexOf('Script');     // 4
'JavaScript'.slice(0, 4);           // "Java"
'um,dois,três'.split(',');         // ["um", "dois", "três"]
'  texto  '.trim();                 // "texto"
'Olá'.repeat(3);                    // "OláOláOlá"
'casa'.replace('a', 'o');           // "coso" (só primeiro)
'casa'.replaceAll('a', 'o');        // "coso"
'123-456'.replace('-', '');         // "123456"

Imutabilidade

let str = 'Hello';
str.toUpperCase();      // Retorna "HELLO", mas str continua "Hello"
str = str.toUpperCase();// Agora str é "HELLO"
🧠 Dica: Strings são imutáveis em JavaScript. Métodos como .toUpperCase() retornam uma nova string — a original não muda.

04. Números & Operadores Aritméticos

Cálculos, Math e formatação numérica

Operadores aritméticos

let a = 10, b = 3;
a + b;   // 13  (soma)
a - b;   // 7   (subtração)
a * b;   // 30  (multiplicação)
a / b;   // 3.333 (divisão)
a % b;   // 1   (resto da divisão)
a ** b;  // 1000 (exponenciação: 10³)

// Incremento / Decremento
let n = 5;
n++;     // 5 (pós-incremento, retorna 5, depois vira 6)
++n;     // 7 (pré-incremento, vira 7, retorna 7)
n--;     // 7
--n;     // 5

Number e conversão

Number('123');          // 123
Number('12.5');         // 12.5
Number('abc');          // NaN (Not a Number)

parseInt('100px');      // 100 (ignora o "px")
parseFloat('3.14cm');   // 3.14

isNaN(NaN);             // true
isNaN('abc');           // true
isNaN(123);             // false

// Verificar se é número finito
isFinite(10 / 0);       // false (Infinity)

Math — biblioteca matemática

Math.PI;              // 3.141592...
Math.round(3.6);      // 4  (arredonda)
Math.floor(3.9);      // 3  (para baixo)
Math.ceil(3.1);       // 4  (para cima)
Math.trunc(3.9);      // 3  (remove decimais)
Math.random();        // 0.0 a 0.999 (aleatório)
Math.max(1, 5, 3);    // 5
Math.min(1, 5, 3);    // 1
Math.abs(-10);        // 10 (valor absoluto)
Math.pow(2, 3);       // 8  (2³) — prefira **

Formatação de números

(1234.5).toFixed(2);          // "1234.50"
(0.1 + 0.2).toFixed(1);       // "0.3" (resolve imprecisão)
(1234567.89).toLocaleString('pt-BR');  // "1.234.567,89"
⚠️ Atenção: 0.1 + 0.2 não é exatamente 0.3 em JS (imprecisão de ponto flutuante). Use toFixed() ou multiplique por 100 para trabalhar com centavos.

05. Comparação & Operadores Lógicos

Tomando decisões com expressões booleanas

Comparação

5 == '5';    // true  (igual — compara valor, ignora tipo)
5 === '5';   // false (estritamente igual — valor E tipo)
5 != '5';    // false
5 !== '5';   // true

10 > 5;      // true
10 < 5;      // false
10 >= 10;    // true
10 <= 5;    // false

// Comparação de objetos (por referência)
[] === [];   // false (são objetos diferentes)
const a = {}; const b = a;
a === b;     // true (mesma referência)

Operadores lógicos

// AND (&&) — todas as condições precisam ser true
true && true;      // true
true && false;     // false

// OR (||) — pelo menos uma condição true
true || false;     // true
false || false;    // false

// NOT (!) — inverte o valor
!true;             // false
!false;            // true
!'texto';          // false (truthy invertido)

// Short-circuit (curto-circuito)
const nome = usuario.nome || 'Anônimo';  // se null/undefined, usa fallback
const idade = usuario.idade && usuario.idade.toFixed(0);  // executa se existir

Operador ternário

const idade = 18;
const status = idade >= 18 ? 'Maior' : 'Menor';
//                     ↑ condição  ↑ se true   ↑ se false

// Encadeado (use com moderação)
const cor = tipo === 'erro' ? 'red' : tipo === 'aviso' ? 'yellow' : 'blue';

Nullish Coalescing (??) — ES2020

const valor = 0;
valor || 'fallback';      // "fallback" (0 é falsy!)
valor ?? 'fallback';      // 0 (?? só ignora null/undefined)

// Optional Chaining (?.) — ES2020
const cidade = usuario?.endereco?.cidade;  // se algo for null/undefined, retorna undefined
🧠 Dica: Sempre prefira === e !== em vez de == e !=. A comparação estrita evita bugs sutis de coerção automática de tipo.

06. Arrays

Listas ordenadas de dados

Criação e acesso

const frutas = ['Maçã', 'Banana', 'Laranja'];
frutas[0];            // "Maçã"
frutas[frutas.length - 1];  // "Laranja" (último)
frutas.length;        // 3

Adicionar e remover

frutas.push('Uva');     // adiciona no final
frutas.pop();           // remove do final
frutas.unshift('Morango');  // adiciona no início
frutas.shift();         // remove do início
frutas.splice(1, 1);    // remove 1 elemento no índice 1
frutas.splice(1, 0, 'Manga');  // insere "Manga" no índice 1

Iteração (percorrer)

// for clássico
for (let i = 0; i < frutas.length; i++) {
  console.log(frutas[i]);
}

// for...of (moderno, recomendado)
for (const fruta of frutas) {
  console.log(fruta);
}

// forEach
frutas.forEach((fruta, index) => {
  console.log(`${index}: ${fruta}`);
});

Métodos funcionais (map, filter, reduce)

const nums = [1, 2, 3, 4, 5];

// map — transforma cada elemento
const dobrados = nums.map(n => n * 2);     // [2, 4, 6, 8, 10]

// filter — filtra elementos
const pares = nums.filter(n => n % 2 === 0); // [2, 4]

// reduce — reduz a um valor
const soma = nums.reduce((acc, n) => acc + n, 0); // 15

// find — encontra o primeiro
const primeiroPar = nums.find(n => n % 2 === 0);  // 2

// some / every
nums.some(n => n > 4);   // true (pelo menos um é > 4)
nums.every(n => n > 0);  // true (todos são > 0)

// includes
nums.includes(3);        // true

Spread e destructuring

// Spread — copiar / concatenar
const a = [1, 2];
const b = [...a, 3, 4];        // [1, 2, 3, 4]
const copia = [...a];           // cópia rasa

// Destructuring — extrair valores
const [primeiro, segundo] = frutas;
const [prim, , terc] = frutas;  // pula o segundo
🧠 Dica: map, filter e reduce são imutáveis — não modificam o array original, retornam um novo. Prefira-os ao for clássico sempre que possível.

07. Objetos

Coleções de pares chave-valor

Criação e acesso

const usuario = {
  nome: 'João',
  idade: 30,
  email: 'joao@email.com',
  'ultimo-acesso': '2024-01-15'   // chave com hífen precisa de aspas
};

usuario.nome;           // "João"       (notação de ponto)
usuario['nome'];        // "João"       (notação de colchetes)
usuario['ultimo-acesso'];  // necessário com hífen

// Adicionar / modificar
usuario.telefone = '11999999999';
usuario.idade = 31;

Métodos e this

const pessoa = {
  nome: 'Ana',
  saudacao() {                      // método (shorthand)
    return `Olá, sou ${this.nome}`; // this = o próprio objeto
  }
};

pessoa.saudacao();  // "Olá, sou Ana"

Iteração em objetos

// Object.keys — array das chaves
Object.keys(usuario);   // ["nome", "idade", "email"...]

// Object.values — array dos valores
Object.values(usuario);

// Object.entries — array de [chave, valor]
Object.entries(usuario).forEach(([chave, valor]) => {
  console.log(`${chave}: ${valor}`);
});

Spread e destructuring

// Spread — clonar / mesclar
const copia = { ...usuario };
const completo = { ...usuario, ativo: true };

// Destructuring — extrair propriedades
const { nome, idade, email } = usuario;
const { nome: nomeUsuario } = usuario;  // renomeando

// Destructuring com valor padrão
const { cargo = 'Visitante' } = usuario;
🧠 Dica: Use Object.freeze(obj) para tornar um objeto imutável (read-only). Use Object.assign({}, obj) ou { ...obj } para clonar.

08. Funções

Blocos de código reutilizáveis

Declaração vs Expressão

// Declaração (hoisted — pode chamar antes de declarar)
function soma(a, b) {
  return a + b;
}

// Expressão (não hoisted — precisa declarar antes)
const mult = function(a, b) {
  return a * b;
};

// Arrow function (moderno, recomendado)
const div = (a, b) => a / b;
const quadrado = x => x * x;       // um parâmetro: sem parênteses
const vazia = () => 'sem params';

Parâmetros

// Valor padrão
function cumprimentar(nome = 'Visitante') {
  return `Olá, ${nome}`;
}

// Rest params (...)
function somarTodos(...numeros) {
  return numeros.reduce((acc, n) => acc + n, 0);
}
somarTodos(1, 2, 3, 4);  // 10

Escopo e Closure

// Escopo global
const global = 'acessível em qualquer lugar';

function teste() {
  // Escopo de função
  const local = 'só dentro da função';

  if (true) {
    // Escopo de bloco (let/const)
    const bloco = 'só dentro do if';
    var antigo = 'vaza do bloco!';  // var ignora escopo de bloco
  }

  console.log(antigo);  // funciona (var vazou)
}

// Closure — função "lembra" do escopo onde foi criada
function contador() {
  let count = 0;
  return function() {
    count++;
    return count;
  };
}
const c = contador();
c();  // 1
c();  // 2

Arrow functions e this

const pessoa = {
  nome: 'João',
  saudacaoTradicional: function() {
    console.log(this.nome);  // this = pessoa
  },
  saudacaoArrow: () => {
    console.log(this.nome);  // this = escopo externo (window/undefined!)
  }
};

pessoa.saudacaoTradicional(); // "João"
pessoa.saudacaoArrow();       // undefined (não use arrow como método!)
⚠️ Importante: Arrow functions não têm seu próprio this — elas herdam do escopo pai. Por isso não funcionam como métodos de objeto.

09. Controle de Fluxo

Condicionais e loops

if / else if / else

const idade = 20;

if (idade < 12) {
  console.log('Criança');
} else if (idade < 18) {
  console.log('Adolescente');
} else if (idade < 60) {
  console.log('Adulto');
} else {
  console.log('Idoso');
}

switch

const dia = 2;
let nomeDia;

switch (dia) {
  case 1:
    nomeDia = 'Domingo';
    break;
  case 2:
    nomeDia = 'Segunda';
    break;
  default:
    nomeDia = 'Inválido';
}

// switch com fallthrough (intencional)
switch (nota) {
  case 'A':
  case 'B':
    console.log('Aprovado');
    break;
  case 'C':
    console.log('Recuperação');
    break;
  default:
    console.log('Reprovado');
}

Loops

// for clássico
for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}

// while
let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}

// do...while (executa pelo menos uma vez)
let j = 0;
do {
  console.log(j);
  j++;
} while (j < 5);

// for...of (arrays, strings, Map, Set)
for (const letra of 'Olá') {
  console.log(letra);
}

// for...in (objetos — cuidado!)
for (const chave in usuario) {
  console.log(chave, usuario[chave]);
}

// break / continue
for (let i = 0; i < 10; i++) {
  if (i === 3) continue;  // pula o 3
  if (i === 7) break;     // para no 7
  console.log(i);         // 0, 1, 2, 4, 5, 6
}
🧠 Dica: Prefira for...of para arrays e for...in apenas para objetos. Evite for...in em arrays porque ele itera sobre o índice como string e inclui propriedades herdadas.

10. DOM — Document Object Model

Manipulando elementos HTML com JavaScript

Selecionar elementos

// Clássico (retorna UM elemento)
document.getElementById('meu-id');
document.getElementsByClassName('minha-classe');
document.getElementsByTagName('div');

// Moderno (recomendado)
document.querySelector('.minha-classe');    // primeiro que encontrar
document.querySelector('#meu-id');
document.querySelectorAll('div > p');       // todos (NodeList)

Manipular conteúdo

const el = document.querySelector('.titulo');

el.textContent = 'Novo texto';         // só texto (seguro)
el.innerHTML = '<strong>Texto</strong>';  // HTML (risco XSS)
el.innerText = 'Texto visível';        // respeita display:none

// Atributos
el.setAttribute('data-id', '123');
el.getAttribute('data-id');     // "123"
el.removeAttribute('disabled');
el.id = 'novo-id';
el.classList.add('ativo');
el.classList.remove('inativo');
el.classList.toggle('dark');
el.classList.contains('ativo'); // true/false

// Estilos inline
el.style.color = 'red';
el.style.backgroundColor = '#333';   // camelCase das props CSS
el.style.cssText = 'color: red; background: blue;';

Criar e remover elementos

const div = document.createElement('div');
div.textContent = 'Olá';
div.className = 'card';

// Adicionar
document.body.appendChild(div);
pai.prepend(div);          // insere no início
pai.insertBefore(div, ref); // insere antes de ref
pai.append(div, outro);     // insere múltiplos no final

// Remover
div.remove();              // moderno
pai.removeChild(div);      // clássico

Eventos

const btn = document.querySelector('button');

// addEventListener (recomendado)
btn.addEventListener('click', function(event) {
  console.log('Clicou!', event.target);
});

btn.addEventListener('mouseenter', () => {
  console.log('Mouse entrou');
});

// Remover evento
function handler() { console.log('ok'); }
btn.addEventListener('click', handler);
btn.removeEventListener('click', handler);

// Event delegation (um listener para vários elementos)
document.querySelector('.lista').addEventListener('click', (e) => {
  if (e.target.tagName === 'LI') {
    console.log('Clicou no item:', e.target.textContent);
  }
});
🧠 Dica: Use textContent em vez de innerHTML sempre que possível — é mais rápido e evita riscos de XSS (injeção de código malicioso). Use innerHTML apenas quando precisar renderizar HTML confiável.

11. Programação Orientada a Objetos

Classes, herança e encapsulamento

Class e constructor

class Pessoa {
  constructor(nome, idade) {
    this.nome = nome;
    this.idade = idade;
  }

  saudacao() {
    return `Olá, sou ${this.nome}`;
  }

  get nascimento() {
    const ano = new Date().getFullYear();
    return ano - this.idade;
  }

  set nascimento(ano) {
    this.idade = new Date().getFullYear() - ano;
  }
}

const joao = new Pessoa('João', 30);
joao.saudacao();           // "Olá, sou João"
joao.nascimento;           // 1994 (get)
joao.nascimento = 2000;    // set → idade vira 24

Herança (extends)

class Aluno extends Pessoa {
  constructor(nome, idade, matricula) {
    super(nome, idade);     // chama o constructor da classe pai
    this.matricula = matricula;
  }

  saudacao() {
    return `${super.saudacao()} — matrícula ${this.matricula}`;
  }
}

const ana = new Aluno('Ana', 22, '2024001');
ana.saudacao();   // "Olá, sou Ana — matrícula 2024001"

Métodos estáticos

class MathUtil {
  static somar(a, b) {
    return a + b;
  }
}

MathUtil.somar(2, 3);  // 5 (não precisa instanciar)

Campos privados (#)

class ContaBancaria {
  #saldo = 0;          // privado (só acessível dentro da classe)

  depositar(valor) {
    this.#saldo += valor;
  }

  get saldo() {
    return this.#saldo;
  }
}

const conta = new ContaBancaria();
conta.#saldo;          // SyntaxError!
conta.saldo;           // 0 (via getter)
🧠 Dica: Use # para propriedades realmente privadas. Por convenção, _propriedade indica "privada" mas ainda é acessível externamente.

12. Programação Assíncrona

Operações que levam tempo (API, arquivos, timers)

setTimeout e setInterval

// Executa uma vez após X ms
const timeout = setTimeout(() => {
  console.log('Passou 2 segundos');
}, 2000);
clearTimeout(timeout);  // cancela

// Executa a cada X ms
const intervalo = setInterval(() => {
  console.log('A cada 1s');
}, 1000);
clearInterval(intervalo);  // para

Promises

// Criar uma Promise
const promessa = new Promise((resolve, reject) => {
  const sucesso = true;

  setTimeout(() => {
    if (sucesso) {
      resolve('Dados carregados!');
    } else {
      reject('Erro ao carregar');
    }
  }, 2000);
});

// Consumir
promessa
  .then(dados => console.log(dados))        // sucesso
  .catch(erro => console.error(erro))       // erro
  .finally(() => console.log('Sempre roda')); // always

async / await (moderno)

async function carregarDados() {
  try {
    const resposta = await fetch('https://api.exemplo.com/dados');
    const dados = await resposta.json();
    console.log(dados);
  } catch (erro) {
    console.error('Falha na requisição:', erro);
  }
}

carregarDados();

Fetch API

// GET
fetch('https://api.exemplo.com/usuarios')
  .then(res => res.json())           // parse do JSON
  .then(dados => console.log(dados))
  .catch(err => console.error(err));

// POST
fetch('https://api.exemplo.com/usuarios', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ nome: 'João', idade: 30 })
})
  .then(res => res.json())
  .then(dados => console.log(dados));

Promise combinadas

// Promise.all — espera TODAS resolverem (se uma falha, tudo falha)
const [users, posts] = await Promise.all([
  fetch('/users').then(r => r.json()),
  fetch('/posts').then(r => r.json())
]);

// Promise.allSettled — espera todas, mesmo com falhas
const resultados = await Promise.allSettled([
  fetch('/users'),
  fetch('/posts-invalidas')
]);

// Promise.race — retorna a primeira que resolver
const timeoutPromise = new Promise((_, reject) =>
  setTimeout(() => reject(new Error('Timeout')), 5000)
);
const dados = await Promise.race([fetch('/dados'), timeoutPromise]);
🧠 Dica: async/await é açúcar sintático sobre Promises. Use try/catch para tratar erros. Lembre-se: uma função async sempre retorna uma Promise.

13. Tratamento de Erros

Código que não quebra — lida com falhas

try / catch / finally

try {
  const resultado = operacaoRiscada();
  console.log(resultado);
} catch (erro) {
  console.error('Algo deu errado:', erro.message);
} finally {
  console.log('Sempre executa (com erro ou não)');
}

throw — lançar erros

function dividir(a, b) {
  if (b === 0) {
    throw new Error('Divisão por zero não permitida');
  }
  return a / b;
}

try {
  dividir(10, 0);
} catch (erro) {
  console.error(erro.message);
}

Tipos de erro no JS

new Error('Erro genérico');
new TypeError('Tipo inválido');
new ReferenceError('Variável não existe');
new SyntaxError('Erro de sintaxe');
new RangeError('Valor fora do intervalo');

Performance

// Debounce — executa após um intervalo sem novas chamadas
function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

// Throttle — executa no máximo uma vez a cada intervalo
function throttle(fn, limit) {
  let inThrottle;
  return (...args) => {
    if (!inThrottle) {
      fn(...args);
      inThrottle = setTimeout(() => inThrottle = false, limit);
    }
  };
}
